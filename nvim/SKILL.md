# Configuring Neovim

## Contextual information

I use lazyvim as my set up for nvim with lazynvim as the plugin manager. All of the plugin will be installed at the directory `~/.local/share/nvim/lazy/`.

## Search for files

When configuring Neovim, the plugins that is required for the configuring are ALMOST ALWAYS on my machine at the directory `~/.local/share/nvim/lazy/`. ALWAYS CHECK AT THE `~/.local/share/nvim/lazy/` for the plugin FIRST. If the plugin does not exist in the local directory, ONLY then you are allow to search on the internet. When searching YOU ARE NOT ALLOWED TO DOWNLOAD ANYTHING FROM THE INTERNET.

## Modifying plugins

If any modification/edit is needed, you are not allowed to make the modification directly in the directory `~/.local/share/nvim/lazy/`, ALWAYS add the modification/edit at the directory `~/.config/nvim`
